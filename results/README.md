# Experiment outputs

Generated checkpoints, predictions, plots, caches, and metric tables are not
versioned with the source code. Keep active cloud outputs on persistent storage
and copy final paper tables or selected figures into their dedicated manuscript
locations only after validation.

- `legacy_archive/README.md` indexes the pre-refactor result scopes that remain
  available in the local working copy.
- `physics_loss_refactor/README.md` defines the output boundary for the current
  physics-loss implementation.

Removing a result from Git tracking does not delete the corresponding local
artifact.
