# Legacy archive

This directory contains historical experiment pipelines that are preserved for
reproducibility but are no longer the project's default execution path.

- `pre_validation_v2/`: the original root-level training, demo, ablation, and
  visualization scripts, together with their shared modules and environment
  notes.

New development and new experiment outputs must use `validation_v2/`,
`configs/validation_v2/`, and `results/physics_loss_refactor/`.
